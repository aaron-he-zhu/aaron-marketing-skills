# Reporting Reference

Reports must be assembled from validated artifacts, not from memory or untracked analysis.

## Recommended Structure

1. Executive summary.
2. Objective, audience, and scope.
3. Data sources and quality notes.
4. Methodology and preprocessing summary.
5. Key metrics and descriptive statistics.
6. Segment, trend, comparison, or model results as appropriate.
7. Visual evidence with interpretations.
8. Findings, recommendations, limitations, and next questions.
9. Appendix with artifact paths, formulas, and assumptions.

## Findings Format

Each report finding should map to an entry in `output/artifacts/analysis_findings.json` and include:

- Claim.
- Evidence.
- Source chart, table, or artifact path.
- Scope and limitation.
- Confidence level.
- Recommended action or next question.

## SEO/GEO Reporting

Separate observed data from recommended action. Use distinct language for:

- Performance changes shown by the dataset.
- Plausible explanations that need corroboration.
- Optimization opportunities.
- Follow-up work requiring crawl, SERP, rank, content, or authority review.
